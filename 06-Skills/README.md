# 06-Skills — Atomic AI Capabilities & Function Tools

## 📌 Purpose
The `06-Skills` module houses the foundational intelligence library of FUTRIX. Skills are atomic, reusable, versioned capabilities that power every AI Executive (`03-Executives`), Department (`04-Departments`), AI Employee (`05-AI-Employees`), and Automation workflow (`08-Automation`).

## 👤 Owner & Scope
- **Owner**: AI CTO, AI CRO, & Academic Engineering
- **Scope**: Enterprise-wide intelligence sharing. Executives and Employees import these Skills directly to eliminate code and logic duplication.

## 🔗 Dependencies
- **Upstream Dependencies**: `00-Codex`, `01-Blueprint`, `02-Frameworks`.
- **Downstream Dependencies**: `03-Executives`, `04-Departments`, `05-AI-Employees`, `08-Automation`.
