## 📌 Overview

**FAIOS (FUTRIX AI Operating System)** is the foundational, enterprise-grade AI Operating System governing all autonomous intelligence, executive decision-making, departmental workflows, pedagogical agents, and data pipelines across FUTRIX.

FAIOS is not mere documentation or prompt collections. It is an executable, modular operating framework designed for a 10-year growth trajectory. It enables a solo founder to orchestrate an entire AI-native education ecosystem with zero initial SaaS overhead, leveraging free-tier cloud infrastructure, automated n8n webhooks, Supabase database triggers, and Google Gemini / Antigravity AI engines.

---

## 🏛 Core Principles

1. **Student First**: Every decision, algorithm, and feature must directly improve student learning velocity, clarity, or growth.
2. **Founder Approval Loop**: All major executive decisions, category expansions, resource allocations, and code deployments generated by AI Executives require human Founder verification via the integrated Telegram Bot Approval Gate.
3. **Data Before Opinion**: Category expansions (e.g., School, Govt Exams, Skills) are strictly prohibited until data-driven Product-Market Fit (PMF) is proven and approved.
4. **Bootstrap First (Zero SaaS Cost)**: Default stack strictly utilizes free tier tools (GitHub, Supabase, Gemini, n8n, Cloudflare, UptimeRobot, Bitwarden).
5. **Privacy & Ethics First**: Zero student data leakage, strict Row-Level Security (RLS), and zero hallucination tolerances in academic content.

## ⚡ Quick Start & Multi-Agent Invocation Protocol

### Reading Module Rules
Each subdirectory within FAIOS contains its own standalone `README.md` and `CHANGELOG.md`. AI Agents operating within FAIOS **must** inspect the module's `README.md` before reading or executing files inside that directory.

### Executing Founder Telegram Approval Gate
When the AI CEO or any AI Executive reaches an execution gate (e.g. initiating content batching or recommending category expansion):
1. The AI Agent formats a structured JSON proposal.
2. The proposal is dispatched via the n8n webhook to the FUTRIX Founder Telegram Bot.
3. The AI Agent enters a polling/wait state until the Telegram callback returns `APPROVED` by the Founder.
