## 📌 Mission & Scope

The **Academic Engineering Department** is responsible for building, auditing, and maintaining India's highest quality, zero-hallucination competitive exam question banks, step-by-step video solution scripts, mock test papers, and topic-wise difficulty indices.

---

## 🔬 Content Verification Protocol (4-Tier Verification)

All academic content must pass a strict 4-Tier Verification Pipeline before deployment:

```
[ Tier 1: Question Generation ]  -->  AI Tutor / Content Creator Agent
              |
              v
[ Tier 2: Syllabus & Taxon Check ] -->  Verify against 09-Knowledge syllabus matrices
              |
              v
[ Tier 3: Mathematical Solver ]   -->  Dual LLM Solver validation (Gemini + Solver Tool)
              |
              v
[ Tier 4: Founder Approval Gate ] -->  Published to Supabase upon Founder Telegram Approval
```
