# Department 05 (Marketing) — Reel Production & Advance Social Scheduling Workflow

> **Department**: Marketing  
> **Target Tooling**: Google Flow Omini, Gemini API, Canva Free, n8n, Instagram Reels, YouTube Shorts  
> **Status**: Production Standard (v1.0.0)  

---

## 🔄 End-to-End Operational Workflow

```
+-----------------------------------------------------------------------+
| STEP 1: MARKET RESEARCH & TREND SCANNING                              |
| Daily automated scan of viral NEET/JEE educational reel formats.       |
| Identifies high-curiosity concepts (e.g. "Why 99% Fail Ray Optics").  |
+-----------------------------------------------------------------------+
                                  |
                                  v
+-----------------------------------------------------------------------+
| STEP 2: SCRIPTING & PERMANENT AVATAR PROMPT GENERATION                |
| Formats script to 200-220 WPM energetic presenter delivery.           |
| Enforces Avatar Identity Lock (Preserves face, beard, skin, eyes).    |
| Incorporates reference reels sent by Founder via Telegram (if any).  |
+-----------------------------------------------------------------------+
                                  |
                                  v
+-----------------------------------------------------------------------+
| STEP 3: GOOGLE FLOW VIDEO RENDERING                                   |
| Generates documentary-style video reels using Google Flow Omini.      |
| Validates Mute-Test Rule (visuals explain 100% of concept).            |
+-----------------------------------------------------------------------+
                                  |
                                  v
+-----------------------------------------------------------------------+
| STEP 4: SUBMISSION TO AI CEO & FOUNDER TELEGRAM APPROVAL GATE          |
| Assembles package JSON (video URL, caption, scheduled posting time).  |
| AI CEO dispatches to Founder Telegram Bot.                            |
+-----------------------------------------------------------------------+
                                  |
                                  v
+-----------------------------------------------------------------------+
| STEP 5: AUTOMATED ADVANCE SOCIAL SCHEDULING                           |
| Upon receiving Founder Telegram 'APPROVED' callback:                   |
| Automatically schedules post on Instagram Reels and Shorts.           |
| Maintains 7-day advance buffer so content is never missed.             |
+-----------------------------------------------------------------------+
```
