# Department 02 — Software Engineering

## 📌 Purpose
The Software Engineering department builds, tests, and maintains the FUTRIX web app, Supabase Postgres database backend, TypeScript Edge Functions, and n8n integration webhooks using 100% zero-cost open source tools.

## 🎯 Mission
Deliver high-performance, fault-tolerant, sub-100ms API response times for millions of NEET and JEE students with zero paid SaaS overhead.

## 👤 Key Stakeholders & Structure
- **Owner**: Lead Engineering Agent
- **Reporting Executive**: AI CTO (Chief Technology Officer)
- **Internal Customers**: Product, QA, Design, AI Engineering, Infrastructure
- **External Customers**: FUTRIX Mobile Web App Users
