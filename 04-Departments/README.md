# 04-Departments — Operational AI Functional Units & Department Repositories

## 📌 Purpose
The `04-Departments` module organizes the 26 functional divisions of FUTRIX. Each department translates executive strategy into concrete workflows, content, design tokens, code deployments, data pipelines, academic question banks, and student support operations.

## 👤 Owner & Scope
- **Owner**: AI C-Suite Executives (`03-Executives`)
- **Scope**: Enterprise-wide functional execution operating under a **95% Automation / 5% Founder Approval** baseline.

## 🔗 Dependencies
- **Upstream Dependencies**: `00-Codex`, `01-Blueprint`, `02-Frameworks`, `03-Executives`.
- **Downstream Dependencies**: `05-AI-Employees`, `06-Skills`, `07-SOP`, `08-Automation`, `12-Deployment`.
